## Overview

This project covers the fundamentals of system security auditing. The goal is to identify basic security vulnerabilities on a real system by running a structured 4-step checklist, documenting findings, and producing an actionable vulnerability report.

> "You cannot secure an asset that you do not know exists." — CIS Controls 1 & 2

---

## The 4-Step Checklist

| Step | Area | What was checked |
|------|------|-----------------|
| 1 | Identity & Access | Password policy, MFA, account privileges |
| 2 | Software & Patches | Windows Update status, installed hotfixes |
| 3 | Human Perimeter | Screen lock, guest accounts, privilege creep |
| 4 | Network & Endpoint | Firewall status, disk encryption (BitLocker) |
